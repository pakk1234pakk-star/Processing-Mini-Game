# Cat Find Food

A simple adventure mini game developed with **Processing (Python mode)**.


## Game Description

Help the cat "Zi Maa" find food hidden in the house and safely leave without touching the cardboard boxes.

### How to Play

- Use **Arrow Keys** to move the cat
- Press **'S'** to search for food in closets / stove / bookcase
- Press **'D'** to leave the house (only after obtaining food)
- Avoid touching the cardboard boxes, or the game will end
- Press **'A'** to restart after winning or losing

### Game Features

- Random food location every time the game starts
- Multiple search locations (closet, stove, bookcase)
- Win and Game Over conditions
- Simple story-driven gameplay with chat messages

## Technologies

- Processing (Python mode)
- Python

## How to Run

1. Download and install [Processing](https://processing.org/)
2. Install **Python Mode** in Processing
3. Open the `.pde` file
4. Click the Run button
